# 利用規約 追記案:コピー / AI学習 / 競合利用の禁止(適用保留・弁護士確認待ち)

- 作成日: 2026-09-03
- ステータス: **文言確定・未適用**(弁護士確認後に適用する方針)
- 目的: Myaira の画面・機能・コンテンツの複製 / 模倣 / AI学習データ化 / 競合開発への
  利用を、利用規約上で明示的に禁止する。

## 背景(既存の規約でカバー済みの部分)

現行の `第 3 条(禁止事項)`(`lib/terms/terms-content.ts`)には既に次が含まれる:

- 本サービスのリバースエンジニアリング・スクレイピング・過度な API 呼び出し

→ スクレイピング / リバースエンジニアリングは既に禁止済み。以下は「AI / 競合による
コピー」に特化した**追記**。

## 追記する 4 項目(§3 の bullets に追加・確定文言)

1. 本サービスの画面・デザイン・構成・機能・文書を複製・模倣し、または類似・競合する
   サービスの開発・提供に利用する行為
2. 本サービスまたは本サービスから取得したコンテンツを、AI・機械学習モデルの学習・
   開発の用に供する行為
3. ボット・クローラー・自動化ツール等を用い、通常の利用の範囲を超えて本サービスに
   アクセスし、またはデータを収集・蓄積する行為
4. 当社の承諾なく、アカウントを第三者と共有し、または本サービスを第三者に再提供・
   再販売する行為

## 適用手順(弁護士確認後に実施)

1. `lib/terms/terms-content.ts` の `第 3 条(禁止事項)` の `bullets` 配列に、上記 4 項目を
   既存の「リバースエンジニアリング…」の直後に追加する。
2. **`CURRENT_TERMS_VERSION` を改定日(例: `"2026-09-03"`)に更新**し、`TERMS_LAST_UPDATED`
   も合わせて更新する(`lib/terms/terms-content.ts`)。
3. 影響: バージョンが上がるため、**全エージェントが次回ログイン時に再同意を求められる**
   (既存の NDA + 規約 同意ゲート)。リリースのタイミングは再同意イベントを許容できる
   時に合わせること。
4. `lib/terms/terms.test.ts` がバージョン整合を見ているため、テストが通ることを確認。
5. 本番反映は main への push(migration 不要・コードのみ)。

## 注意

- 文言の法的有効性・網羅性は弁護士に確認すること(特に「類似・競合サービスの開発」の
  範囲、独禁法上の相当性など)。
- スクリーンショット / フロントコードの露出は Web では技術的に防止不可。本条項は
  「規約上の禁止=法的抑止」としての位置づけ。技術面の対策(AI クローラー robots ブロック +
  認証エリアの noindex)は 2026-09-03 に別途実装・本番反映済み(commit 8eef55b)。
